# Feature Library and Universal Search Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make every shipped ADCode feature discoverable, explainable, and directly usable from a new activity-bar feature library, the menu bar, and universal title-bar search without removing any existing feature or specialized search shortcut.

**Architecture:** `@adcode/help` becomes the single pure feature catalogue by combining existing help copy with typed setting and command actions. Renderer surfaces consume that catalogue and delegate every action to the existing command registry or settings deep link. `@adcode/search` owns pure universal-result ranking and an async generation coordinator, while the desktop renderer supplies commands, files, recents, and symbols through existing bridges.

**Tech Stack:** TypeScript 5.9, Electron 43, electron-vite/Vite 7, DOM APIs, Vitest 4, existing ADCode semantic CSS tokens, and Markdown documentation generated by `scripts/docs-seed.mjs`.

**Spec:** `docs/superpowers/specs/2026-08-28-feature-library-universal-search-design.md`

## Global constraints

- Preserve the current workbench layout, themes, controls, menus, and specialized shortcuts.
- Follow red-green-refactor for every behavior change: add the focused test, observe the expected failure, implement the smallest coherent change, then rerun the focused and neighboring tests.
- Never invoke complex UI behavior through synthetic DOM clicks. Expose intent-level methods and reuse the same handler function as the visible control.
- Keep `@adcode/help` and `@adcode/search` free of Electron and DOM dependencies.
- Keep feature actions constrained to known command IDs and known setting IDs. Do not pass arbitrary paths or privileged handles through catalogue data.
- Use existing semantic CSS variables, focus treatment, glass material, density hooks, and reduced-motion behavior. Add no new palette, font, emoji icon, or saturated accent.
- Preserve `Ctrl+P` Quick Open, `Ctrl+Shift+P` Command Palette, `Ctrl+T` Symbol Search, and `Ctrl+Shift+F` content Search.
- Commit after every independently testable milestone. Do not combine unrelated user changes with these commits.

export type FeatureAction =
