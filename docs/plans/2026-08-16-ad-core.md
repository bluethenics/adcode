# Ad Core Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build all twelve `packages/ads` modules plus `mock-server`, headless and fully tested, so the editor-shell slice has only adapters left to write.

**Architecture:** `types.ts` holds types and six port interfaces. Five pure modules import only `types.ts` and receive no ports. Three I/O modules receive every capability through a port. Two adapters depend on interfaces; `adService.ts` is the sole composition root. The mock server implements the same wire contract with independently authored types and imports nothing from `packages/`.

**Tech Stack:** TypeScript 5.9.3 (strict, `erasableSyntaxOnly`), Node 24 native type stripping, vitest 4, fast-check 4, dependency-cruiser 18. Zero runtime dependencies.

**Spec:** `docs/specs/2026-08-16-ad-core-design.md`

## Global Constraints

- **Money is `bigint`.** Branded `Micros`. Never `number`, never `toFixed`, never float division. On the wire, money is a decimal **string**.
- **`packages/ads/src` has zero runtime dependencies.** Only `node:` free, no npm imports. Enforced by `ads-ships-zero-runtime-deps`.
- **The five pure modules** (`scheduler`, `validation`, `tagger`, `ledger`, `sponsorsView`) import only `types.ts`, and use no `Date`, `Math.random`, `process`, `fetch`, or `require`.
- **`mock-server` imports nothing from `packages/`.** Its types are hand-written duplicates. Enforced by `mock-server-must-not-import-client`.
- **`packages/ads` never imports `packages/memory`.** Release blocker (§11).
- **All imports use explicit `.ts` extensions** (NodeNext + `allowImportingTsExtensions`).
- **No enums, namespaces, or parameter properties** — `erasableSyntaxOnly` forbids them so Node runs the source directly.
- **Constants:** `SETTLE_MS` 60_000 · `AUTO_DISMISS_MS` 8_000 · `MIN_DWELL_MS` 4_000 · `FETCH_TIMEOUT_MS` 3_000 · `PREFETCH_TARGET` 10 · `RECEIPT_QUEUE_CAP` 500 · `MAX_TAGS` 8.
- **Presets:** `off` 0/0 · `light` 3_600_000/4 · `standard` 1_800_000/8 · `max` 900_000/20.
- **Suppression order, exact:** `ads-disabled` → `kill-switch` → `frequency-off` → `settling` → `window-unfocused` → `debug-active` → `do-not-disturb` → `daily-cap` → `min-interval` → `no-creative`.
- **Verification command:** `npm run verify` (typecheck + firewall + suite).
